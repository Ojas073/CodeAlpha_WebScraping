# CodeAlpha Web Scraping Project

## 📌 Project Overview
This project is developed as part of the CodeAlpha Data Analytics Internship.

The objective is to extract book information from a public website using Python web scraping techniques and convert the collected information into a structured dataset for analysis.

## 🎯 Objectives
- Extract data from a public website.
- Collect book titles, prices, ratings, and availability.
- Scrape information from multiple pages.
- Clean and organize the collected data.
- Export the dataset into CSV and Excel formats.
- Perform basic exploratory data analysis.

## 🛠️ Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- OpenPyXL

## 🌐 Data Source
Website: https://books.toscrape.com/

Books to Scrape is a website designed for practicing web scraping.

## ✨ Features
- Multi-page web scraping
- Book title extraction
- Price extraction
- Rating extraction
- Availability checking
- Product and image URL extraction
- Data cleaning and duplicate removal
- CSV and Excel export
- Automated summary report generation
